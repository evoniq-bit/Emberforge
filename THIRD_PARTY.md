# Third-Party Components and References

Emberforge uses or references third-party work. The corresponding license notices are kept with the source release.

## Zstandard / libzstd

Emberforge includes `libzstd.dll` for Zstandard decompression used by the game catalog functionality.

- Project: Zstandard
- Copyright: Meta Platforms, Inc. and affiliates
- License: BSD

The full license text is included in the source release as `Zstandard-Lizenz.txt`.

## ember-kfc / KFC3 format reference

The game catalog reader was informed by the KFC3 format information from **ember-kfc** by **Zach Landquist**.

Emberforge uses an independently implemented bounded reader, while retaining the upstream license notice for transparency and attribution.

- Copyright: Zach Landquist
- License: MIT

The full license text is included in the source release as `Katalog-Format-Lizenz.txt`.

## Turk645 / Builder's Companion

Several Emberforge ideas and features were inspired by, adapted from or rebuilt from work by **Turk645**, creator of **Builder's Companion** for Enshrouded.

This includes the original concept behind Building Block Override and Object Override, as well as the Glider Flight functionality used as the basis for Emberforge's current glider implementation.

See [CREDITS.md](CREDITS.md) for the full credit notice.
